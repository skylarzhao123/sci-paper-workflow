# 阶段 5：定期刊

读取 `journal-recommender/SKILL.md` 与其要求的参考文件。以稳定摘要和 Discussion 为依据。已有明确目标刊时围绕它核对要求，不强制另找五本。

## 提示词

```text
请根据摘要建立 journal-pool.md，并浏览期刊官网补充当前信息。
摘要与稿件：{实际路径}
研究领域：{实际领域}
研究对象：{实际对象}
方法与数据：{真实内容}
主要发现：{审计后有证据支持的发现}
目标分区/收录要求：{用户偏好或未提供}
时限、OA/APC预算、投稿策略和排除条件：{偏好或未提供}
偏好来源：{用户明确说明、既有记录或明确授权默认的原话}
每本候选期刊一行，包括范围匹配理由、文章类型、投稿要求、开放获取情况/费用、官网链接、查询日期。
按“最适合先投”排序，注明分区/指标年份及无法确认的字段。
不拿历史值冒充当前指标，不承诺录用，不执行投稿或发送稿件。
```

缺偏好且用户未授权默认时，按该 Skill 一次集中询问；已有偏好直接沿用。网络不可用时记录缺口，不伪装成已核验的推荐。

完成条件：候选符合硬条件，匹配有来源，时效字段有查询日期，未知和风险未被默认成无风险。通常 3—5 本，数量服从有效候选与用户范围。
