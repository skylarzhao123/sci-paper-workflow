# 阶段 1：定问题与证据卡

读取 `academic-research-suite/SKILL.md`、`ars/deep-research/WORKFLOW.md`，按需读取问题收束、文献检索、来源核验和综合的角色提示，在本会话执行。模糊方向先收束；清楚问题不重复开题。

## 提示词

```text
我正在推进一篇 SCI 论文。请读取开题材料与核心文献，围绕研究问题建立 question.md 和 evidence-card.md。
研究问题：{研究问题}
研究对象与情境：{研究对象与情境}
已有材料及权威版本：{真实文件列表}
允许补充检索的范围：{研究范围或用户约束}

question.md 明确研究对象、待解释现象、待比较机制/假设及尚未确定的范围。
evidence-card.md 分四部分：
1. 已有研究的共识；
2. 可直接比较的分歧；
3. 与本研究最相关、但证据仍不完整的空缺；
4. 每条判断对应的来源、年份、页码或图表位置。
每条证据分配稳定 E-ID，区分已核验、仅摘要、待定位、未核验。
不要发明文献。无法定位的位置写“待定位”；没有完成相应检索时将空缺标记为待验证候选。
```

完成条件：问题可回答，主要判断有真实可回溯来源，没有未决的关键研究范围问题。全文缺失可明确标记，但依赖未核验材料的中心主张不能被当作已成立。只剩宽泛题目时记录 partial 和必要问题，不编造结果。
