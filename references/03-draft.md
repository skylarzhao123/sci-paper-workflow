# 阶段 3：分节写

读取 `paper-skill/SKILL.md` write 路由及当前章 section guide。每轮一个小节；只需载入相关证据/结果条目，但保留原始位置。

根据材料就绪情况安排 Methods/Results、Introduction/Discussion、Abstract；用户指定顺序优先。无结果不阻止文献支持的引言。完成章节保存新版本、更新 manifest，全文一致性检查后再合稿。

## Results 提示词（对应 PDF）

```text
请为 Results 的第 {小节编号} 小节写英文初稿。
本节问题：{paper-map 对应问题}
允许使用的结果：{真实统计输出、R-ID、图表编号和路径}
允许使用的解释范围：{paper-map 对应范围}
先列发现顺序，再按“发现—量化结果—图表指向”组织为 2—4 个短段落；篇幅据实际材料调整。
所有数值、方向和显著性必须来自提供的材料。不要将机制推断写成测得结果。
最后在正文之外列出仍缺的图表、单位或统计信息。
保存到 {实际新版本路径}，不覆盖前一版本。
```

## 其他章节提示词（衔接补充）

```text
请按 paper-map 为 {章节/小节} 写 {正文语言} 初稿。
本节问题与允许主张：{对应条目}
允许材料：{文件路径与 E/R/图表 ID}
相关章节：{路径或无}
待补材料：{已知缺项}
先安排论证顺序再写正文。保留事实、术语、引文键、统计信息与证据强度。
Methods 只写已提供的真实流程；Discussion 将解释对应到具体发现及文献，区分观察、推断与假说。
Abstract 在主体稳定后总结，不增加主文没有的结果。
缺失事实单列作者问题，可以标记未完成小节，不用虚构内容使稿件看似完整。
保存到 {实际新版本路径}，更新 drafts/manifest.json。
```

完成条件：全流程所需章节有可用稿，图文、数字、术语、引文键一致，保存 `manuscript-vN.md`。章节缺材料时记录 partial。单节请求完成即停止，不把整篇 draft 标完成。
